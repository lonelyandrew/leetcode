# Part 1. 数组&链表

## 理论知识

- 数组
    - 时间复杂度(Average, Worst)
        - Access: $O(1)$, $O(n)$
        - Search: $O(n)$, $O(n)$
        - Insertion: $O(n)$, $O(n)$
        - Deletion: $O(n)$, $O(n)$
    - 空间复杂度: $O(n)$
- 链表
    - 时间复杂度(Average, Worst)
        - Access: $O(n)$, $O(n)$
        - Search: $O(n)$, $O(n)$
        - Insertion: $O(1)$, $O(1)$
        - Deletion: $O(1)$, $O(1)$
    - 空间复杂度: $O(n)$
